# New home page (test build)

`home-block.html` is the Kickstarter-style home page: live "still needed" figure and next milestone, supporters
(top / recent / comments), where the money goes, donor levels, the perks carousel, matching challenges, store and
supporter-access teasers. It reads the same live feeds as /donate and uses the same arithmetic for the Rough Cut total.

- Squarespace holds only `squarespace-loader-block.html`, pasted once into a Code Block on the page.
- `VERSION` names the commit the loader serves. Publishing = commit the block, then write that commit's id into VERSION.
- Donate buttons open Pledge's own donation pop-up (widget 6GNakp1GtmAa92RH).
- Currently for a hidden test page only (Not Linked, hidden from search).
